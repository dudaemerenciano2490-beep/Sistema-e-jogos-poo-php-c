# Sistema de biblioteca
📌 Projeto de Gerenciamento
📖 Sobre o Projeto
Este projeto foi desenvolvido em grupo com foco em Programação Orientada a Objetos (POO), utilizando as linguagens C# e PHP.
O objetivo principal é oferecer um sistema de gerenciamento que facilite o controle e a organização de informações de forma prática e eficiente.

🚀 Tecnologias Utilizadas
C# → Implementação da lógica de negócio e funcionalidades principais.

PHP → Desenvolvimento da camada web e integração com banco de dados.

POO → Estruturação modular e reutilizável do código.

🎯 Funcionalidades
Gerenciamento de usuários

Controle de dados

Interface web para interação com o sistema

Integração com banco de dados

👥 Equipe
Projeto desenvolvido em colaboração por um grupo de estudantes, com foco em aprendizado prático e aplicação de conceitos de desenvolvimento de software.
